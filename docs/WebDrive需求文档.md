# WebDrive - 基于 SMB的现代化 Web 网盘

## 一、项目简介

WebDrive 是一款部署于 NAS 或服务器上的轻量级 Web 网盘。

项目本身**不负责存储文件**，而是将 NAS 已有的 SMB 服务作为底层存储与权限中心，在此基础上提供更加现代化的 Web 文件管理体验。

项目主要解决传统 SMB 在浏览器访问体验、大文件上传、断点续传、文件管理等方面的不足，同时完全兼容 NAS 原有的用户权限体系，无需重新维护用户、目录权限或存储逻辑。

------

## 二、设计目标

### 2.1 保留 SMB 系统原有权限体系

项目不重新设计权限系统，而是直接复用 SMB 的用户权限。

用户登录后，系统使用当前用户的 SMB 身份访问文件，因此：

- 用户只能访问自己拥有权限的目录
- 用户无法越权访问其它目录
- 所有目录权限均由 SMB 负责管理
- WebDrive 不需要维护独立的 ACL

这样可以充分利用威联通、群晖等 NAS 已有的 SMB 权限管理能力。

------

### 2.2 提供现代化 Web 文件管理体验

相比传统 SMB：

- 更友好的界面
- 更高效的上传下载
- 更丰富的文件操作
- 更好的移动端适配
- 更完善的任务管理

无需依赖系统映射网络磁盘即可完成日常文件管理。

------

### 2.3 支持大文件上传

WebDrive 将采用**分片上传**方案：

- 文件自动切片
- 上传失败自动重试
- 支持断点续传
- 支持暂停与恢复
- 上传完成后自动合并

即使部署在存在单请求大小限制的网络环境中，也能够稳定上传超大文件。

------

### 2.4 轻量部署

整个系统采用 Docker 部署。

仅需配置：

- SMB 地址
- SMB 根目录
- 系统监听端口

即可完成部署。

------

# 三、系统架构

```text
Browser

        │

        ▼

WebDrive Server

        │

        ▼

SMB

        │

        ▼

NAS File System
```

系统不直接操作磁盘，而是统一通过 SMB 完成：

- 浏览目录
- 上传文件
- 下载文件
- 删除文件
- 创建目录
- 重命名
- 移动

因此天然兼容：

- 威联通
- 群晖
- Windows SMB
- Apache SMB
- Nginx SMB

等所有标准 SMB 服务。

- 拖拽上传

# 五、上传流程

```
用户选择文件

↓

创建上传任务

↓

文件自动切片

↓

逐片上传

↓

服务器保存临时分片

↓

所有分片上传完成

↓

校验完整性

↓

合并完整文件

↓

写入 SMB

↓

删除临时文件

↓

上传完成
```

整个过程支持：

- 失败重试
- 断点恢复
- 上传暂停
- 上传取消

------

# 六、权限模型

系统自身不维护目录权限。

所有权限来源于 SMB。

例如：

```
User A

↓

SMB

↓

只能访问：

/Users/A
User B

↓

SMB

↓

只能访问：

/Users/B
```

管理员：

```
Admin

↓

SMB

↓

全部目录
```

WebDrive 仅负责展示与操作。

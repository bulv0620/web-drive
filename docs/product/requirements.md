## 1. 产品定义

WebDrive 是一个以 SMB 共享为存储和最终权限边界的 Web 文件管理器。用户使用自己的 SMB 凭据登录，服务端以该用户身份执行文件操作，不建立独立的文件 ACL。

产品重点是改善浏览器中的文件浏览、大文件传输、预览和移动端体验，而不是替代 NAS 的账号、权限或存储管理能力。

## 2. 目标

- 复用 NAS/SMB 已有账号和目录权限，不维护第二套文件授权体系。
- 提供桌面端和移动端一致的现代文件管理体验。
- 在高延迟、低带宽和反向代理环境下可靠传输大文件。
- 文件上传、下载和预览保持流式，避免大文件整体进入 Node.js 内存。
- 使用 Docker 提供可重复、低维护成本的单实例部署方式。
- 在没有真实 SMB 环境时保留完整的 Mock 开发流程。

## 3. 非目标

- 不提供独立用户注册、目录 ACL 或配额管理系统。
- 不绕过 SMB/NAS 权限，也不保证兼容未经验证的所有 NAS 型号与固件。
- 当前不支持多实例水平扩容；会话、上传任务和分享记录仍保存在单进程内存中。
- 当前不提供多 SMB 数据源、全文搜索、Office/CAD 在线预览或插件平台。

## 4. 用户角色

### 4.1 登录用户

使用 SMB 用户名和密码登录，只能访问 SMB 授权范围内的路径，可执行浏览、上传、下载、预览及文件管理操作。

### 4.2 分享访问者

无需登录，通过有效的临时分享链接下载单个文件。访问能力仅限分享记录指定的文件和有效期。

### 4.3 部署管理员

负责配置 SMB、HTTPS 反向代理、端口、上传临时目录、容量上限、会话密钥和监控；系统当前没有 Web 管理后台。

## 5. 当前能力

### 5.1 身份与权限

- SMB 用户名和密码登录。
- 所有 SMB 操作使用当前会话凭据。
- HttpOnly、SameSite=Strict、HMAC 签名 Cookie。
- 登录失败限流、会话数量与有效期限制。

### 5.2 文件浏览与管理

- 列表和网格视图、面包屑、搜索、排序与多选。
- 新建文件夹、删除、重命名、移动和批量删除。
- 桌面端和移动端适配，中英文界面。

### 5.3 上传

- 文件、文件夹和拖放上传。
- 分片上传、断点恢复、暂停、继续、取消和人工重试。
- 页面级最多 3 个在途分片；瞬时网络错误按单分片自动重试。
- 分片流式写入本地临时目录，校验后登记为 `.part`。
- 完成时顺序读取分片，通过单个 SMB write stream 写入目标路径。

详细设计和环境验收见已归档的 [SPEC-001](../specs/archive/spec-001-upload-reliability.md)。

### 5.4 下载、分享与预览

- 单文件流式下载及单 Range 请求。
- 单文件临时分享链接。
- 图片、视频、音频、Markdown、代码/文本和 PDF 预览。
- Markdown 在写入 DOM 前经过清理；主动内容格式按纯文本响应。

## 6. 规划能力

以下能力尚未纳入当前实现基线，实施前需要独立 Spec：

- 多文件打包下载和下载任务中心。
- 文件复制、批量移动、收藏、最近访问和回收站。
- Web 系统设置或管理员控制台。
- Office/CAD 预览、全文搜索、标签和多 SMB 数据源。
- 外部会话/任务存储及多实例部署。
- 支持 SMB3 加密且经过真实 NAS 兼容验证的新 SMB 客户端。

## 7. 核心质量要求

### 7.1 安全

- 所有 drive path 必须限制在 `SMB_ROOT` 内。
- 用户间不得串用会话、SMB 凭据、上传任务或分享记录。
- 日志不得记录密码、Cookie 或完整凭据。
- 生产部署必须位于 HTTPS 反向代理后方。

### 7.2 性能与可靠性

- 大文件传输必须流式处理。
- 上传临时空间和任务数量必须有硬上限。
- 分片中断不得产生可被断点恢复误认的完整分片。
- Range 下载必须正确处理空文件、开放区间、suffix 和越界请求。

### 7.3 兼容性与体验

- 支持 Node.js 20+ 和 Docker Compose。
- 新功能同时覆盖桌面端、移动端、英文和简体中文。
- 预览的大型依赖按需加载，避免无条件增加首屏 bundle。
- 无真实 SMB 时可使用 Mock 完成前端开发和基础交互验证。

## 8. 发布基线

每项影响 API、上传、下载、权限或部署的变更至少需要：

- 通过 `npm test`。
- 通过 `npm run build:web`。
- 更新对应 Spec 与相关基线文档。
- 使用 Mock 验证受影响的交互。
- 涉及 SMB 特性的变更在发布说明中明确真实 NAS 验证状态。

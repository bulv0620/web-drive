此检查表区分仓库已经提供的防护、部署方必须完成的配置，以及只有真实 SMB/NAS 环境才能验证的事项。它不是一次性任务；每次发布、NAS 固件升级或代理链路变化后应重新检查相关项目。

## 1. 仓库内已实施

- [x] 上传取消接口限制任务 ID 和会话归属，避免本地路径穿越及任意递归删除。
- [x] 校验上传文件名、分片索引、分片大小、单文件上限、临时空间和任务数量。
- [x] 临时目录和文件尽可能使用 `0700` / `0600`；不支持 `chmod` 时执行真实写入探测。
- [x] 主动内容预览按纯文本响应并启用 `nosniff`。
- [x] 配置 CSP、frame、referrer、permissions policy 和敏感响应禁用缓存。
- [x] 拒绝浏览器跨源写请求；Cookie 使用 SameSite=Strict，生产模式默认 Secure。
- [x] 未登录接口不公开 SMB 地址、域、根目录和本地上传目录。
- [x] 登录失败限流，并限制全局/单用户会话数、分享有效期和数量。
- [x] HTTP 请求超时可配置，单连接请求数有限制。
- [x] Compose 默认回环发布端口、非 root、只读根文件系统并移除 Linux capabilities。
- [x] 服务端安全回归测试已纳入 `npm test`。

## 2. 部署前必须完成

- [ ] 使用 HTTPS 反向代理，强制 HTTP 跳转 HTTPS。
- [ ] 确认公网无法绕过反向代理直接访问应用端口。
- [ ] 生成高熵 `AUTH_TOKEN_SECRET`，存入密钥管理系统并制定轮换流程。
- [ ] 仅在受信代理后启用 `TRUST_PROXY`，并确认真实客户端 IP 传递正确。
- [ ] NAS、WebDrive 与反向代理之间位于可信隔离网络或 VPN。
- [ ] 为上传临时目录配置正确 UID/GID、容量和持久化挂载。
- [ ] 根据最慢上行速度统一检查 WebDrive、反向代理和 FRP 的请求超时。
- [ ] 配置磁盘空间、容器重启、HTTP 5xx、登录失败和 SMB 错误监控。
- [ ] 限制日志采集，禁止记录请求体、Cookie 和 SMB 凭据。
- [ ] 定期执行依赖审计和容器镜像扫描。

## 3. FRP / 反向代理验证

- [ ] 上传一个单分片耗时超过 120 秒的测试文件。
- [ ] 验证代理没有缓存整个请求体后再转发。
- [ ] 验证并发 3 个分片时没有意外单连接限速或空闲超时。
- [ ] 模拟短暂断网，确认浏览器重试后已完成分片仍可复用。
- [ ] 确认代理返回的 408、429 和 5xx 可被客户端正确识别。

## 4. 真实 SMB / NAS 专项验证

- [ ] 覆盖登录成功、密码错误、权限拒绝和会话退出。
- [ ] 覆盖目录列表、新建、重命名、移动、递归删除和同名文件行为。
- [ ] 覆盖空文件、首尾字节、开放 Range、suffix Range 和越界 Range。
- [ ] 覆盖大文件上传、暂停恢复、取消、完成阶段断线和服务重启残留。
- [ ] 验证长时间流式写入、文件句柄仅关闭一次以及最终文件大小。
- [ ] 评估远端临时文件和原子重命名，避免 SMB 失败暴露最终路径半成品。
- [ ] 记录 NAS 型号、固件、SMB 方言、测试日期和结果。

## 5. 后续安全工程

- [ ] 评估替换 `@marsaud/smb2`；候选客户端需支持 SMB3、消息签名和传输加密。
- [ ] 新客户端通过受支持 NAS 型号和固件的兼容矩阵。
- [ ] 替换完成后移除 `--openssl-legacy-provider` 并重新验证登录与传输。
- [ ] 若引入多实例，使用外部会话/分享/任务存储并建立凭据加密和密钥轮换方案。
